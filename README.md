# ДЗ 12: Реализовать сервер и клиент gRPC

## Описание

* .proto файл с сущностями и методами, а также скомпилированный protobuf-код находится в директории `proto`
* gRPC-сервер реализован в пакете `packages/internal/grpc`
* Порт для поключения: 50001
* gRPC-клиент находится в `grpc_client/main.go`

## Инструкция для тестового запуска
* Запустите сервер, выполнив из корневой директории проекта
```bash
go run packages/launch/main.go
```
* Откройте еще один терминал. Выполните команду для запуска клиента
```bash
go run grpc_client/main.go
```
